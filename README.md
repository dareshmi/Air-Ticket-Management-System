# Air Ticket Management System

## Project Overview

The **Air Ticket Management System** is a desktop-based application developed using **C#** and **SQL Server** to automate airline ticket booking and flight management operations.

The system provides a centralized platform for **administrators, employees, and passengers** to manage flight information, reservations, and passenger records. It is designed to reduce manual paperwork, improve data accuracy, and provide quick access to flight and booking information.

## Main Goal

To provide a **fast, secure, and user-friendly platform** for managing airline ticket reservations and flight information.

## Scenario

Air travel has become one of the most popular means of transportation, creating a growing need for efficient ticket reservation and flight management systems. Traditional ticket booking methods often involve manual record keeping, long waiting times, and a higher chance of human error.

The Air Ticket Management System addresses these challenges by providing a centralized platform where:

- **Administrators** manage employee accounts and oversee system operations.
- **Employees** maintain flight schedules, update flight information, and assist with booking-related tasks.
- **Passengers** register accounts, search available flights, book tickets, and view reservation details.

A passenger can register and log in to the system, browse available flights based on source, destination, and travel date, select a suitable flight, and book a ticket. The booking information is stored in the database and linked with the passenger and flight records.

## Features

### 1. User Authentication

- Secure login system for Admin, Employee, and Passenger
- Passenger registration using passport number, email, and password
- Role-based access control

### 2. Flight Management

- Add new flight records
- Store flight code, source, destination, takeoff date, and available seats
- View all available flights

### 3. Employee Management

- Add, update, and manage employee information
- Store employee ID, name, nationality, phone number, and gender
- View employee records through a dashboard

### 4. Ticket Booking System

- Select flights from available flight records
- Generate booking records linked to passengers
- Store passenger details and booking amount

### 5. Passenger Management

- Passenger registration and login
- Search booking information using Ticket ID/Booking ID
- View personal booking details

### 6. Database Integration

- SQL Server database for centralized data storage
- Efficient retrieval and management of flight, passenger, employee, and booking records
